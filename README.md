# MTZ PRO – Szerelési Mesterkönyv

Magyar nyelvű, mobilbarát MTZ tudástár, hibakereső és napi karbantartási ellenőrzőlista.

## Funkciók
- 16 választható MTZ-modell
- 12 szerelési témakör
- Gyakori hibajelenségek és első ellenőrzések
- Napi ellenőrzőlista, helyi mentéssel
- Kedvencek mentése
- PWA / offline gyorsítótár
- Reszponzív, piros-fekete felület

## GitHub Pages bekapcsolása
1. Nyisd meg a repository **Settings** menüjét.
2. Válaszd a **Pages** részt.
3. A **Build and deployment** résznél válaszd: **Deploy from a branch**.
4. Branch: **main**, mappa: **/(root)**, majd **Save**.
5. Néhány perc múlva az oldal címe: https://mokus91.github.io/Mtz-szerel-/

## Fontos
A beépített leírások általános hibakeresési és biztonsági tájékoztatók. Nyomatékot, hézagot, olajmennyiséget vagy beállítási értéket csak az adott motor-, váltó- és traktorkivitel gyári kézikönyvéből szabad megadni. A külső MTZ 820/952 PDF csak a benne megjelölt kivitelekhez használható.

## Fájlok
- `index.html` – alkalmazás
- `manifest.webmanifest` – telepíthető alkalmazás beállításai
- `sw.js` – offline gyorsítótár
- `icon.svg`, `icon-192.png`, `icon-512.png` – ikonok
